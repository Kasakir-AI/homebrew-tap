# Kasakir-AI Homebrew tap

```sh
brew install --cask kasakir-ai/tap/update-workbench
```

| Cask | App |
| --- | --- |
| `update-workbench` | [Update Workbench](https://github.com/Kasakir-AI/UpdateWorkbench): finds and installs updates for Mac apps and Homebrew packages. |

Update with `brew upgrade`. Update Workbench installed this way also updates itself through Homebrew.

Update Workbench is ad-hoc signed and not notarized by Apple. The cask removes the download quarantine flag after installing so the app opens normally; if you'd rather approve it yourself, download the DMG from the app's Releases page instead.
